Was wir tun

Engineering und Beratung aus einer Hand – von den Leuten, die den Code schreiben.

  • Java · Spring Boot

    Enterprise Java & Spring

    Entwurf und Entwicklung von Backend-Services und APIs – vom neuen Service bis zum langlebigen System, das sorgfältig weiterentwickelt werden muss.

  • BPMN · DMN · Camunda

    Prozessautomatisierung

    Prozessmodelle, Entscheidungstabellen und Process-Engine-Anwendungen mit Camunda, inklusive Tests und Betrieb langlaufender Workflows.

  • REST · Messaging · TM Forum Open APIs

    Systemintegration

    Systeme über klar definierte APIs und Events verbinden: Adapter, Schnittstellenverträge, Fehlerbehandlung und Tests, die Schnittstellen verlässlich halten.

  • Order · Service · Resource

    Telekom-OSS/BSS-Beratung

    Beratung zu Auftragsmanagement, Fulfillment- und Inventarprozessen für Telekommunikationsanbieter – vom Entwurf bis zur Umsetzung.
